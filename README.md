# Тайный Санта 🎅

Комнаты для Тайного Санты: жеребьёвка, ручное назначение Сант, ёлка с подарками, упаковка и принятие подарков.

[Тайный Санта](https://winstonpub.github.io/secretsanta/)

Сайт полностью бесплатный: статические страницы на **GitHub Pages**, база данных и вход — **Supabase** (браузер обращается к нему напрямую, логика выполняется функциями в базе данных).

Пошаговая инструкция по запуску: [INSTRUCTION.md](INSTRUCTION.md).
